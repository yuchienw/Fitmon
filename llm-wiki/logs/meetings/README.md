# 會議紀錄 (Meeting Notes)

本目錄存放人機協作與專案決策的會議紀錄，供後續對話對齊，而不取代 [`PROJECT_STATE.md`](../../PROJECT_STATE.md) 的即時看板，也不取代 [`changelog.md`](../changelog.md) 的演進因果鏈。

## 命名規則

檔名格式：`YYYY-MM-DD_主題.md`（例：`2026-11-10_決策同步.md`）。同一日多場會議應使用可區分的主題，勿覆蓋既有檔案。

## 每份紀錄應包含的欄位

1. **日期**
2. **參與者**
3. **來源**（紀錄根據什麼寫成，例如現場、轉述、哪一次對話）
4. **重點**
5. **決策**（每一項都必須標明決策者）
6. **待辦**（負責人／期限；若來源未指定，寫「待指定」）
7. **未決事項**

## 記載原則

- **只記 YuChien 親口決定**為「決策」。
- 他人意見、建議、轉述中尚未經 YuChien 拍板的內容，一律標為「提議」，不得寫成已決定。
- 沒有來源的事實不要補寫；不確定處標為「待確認」。
